# 小白个人站与综合导航系统 (a.21212121.xyz)

本项目为部署在 `a.21212121.xyz` 上的综合个人门户、导航聚合与轻量工具站集合，全面适配现代 PHP 运行环境。

## 目录结构与功能
- `index.html`: 门户主页与快速入口
- `dh/`: 网址导航与实用链接聚合
- `bb/`: 表白墙 / 留言便签应用
- `db/`: 数据管理与备份接口
- `l/`: 短链接重定向与分流
- `a/`: 个人相册与素材展示集合

## 本地开发与线上部署
- 本地调试：支持使用 PHP 内置开发服务器：`php -S 127.0.0.1:8080`
- 线上部署：配置 Nginx 根目录指向当前目录，支持 HTTPS 伪静态。
