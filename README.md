# 杂项 / 小白个人数字化全景空间 (a.21212121.xyz)

本项目为部署在 `a.21212121.xyz` 上的综合个人门户、记忆归档与轻量前端应用全景集合，全面适配现代浏览器与 PHP 运行环境，支持纯静态离线运行与云端多端自适应。

---

## 🌟 核心架构与模块整合

### 1. 全新聚合总门户 (`/index.html`)
- **视觉风格**：深空曜黑（Deep Obsidian）+ 极光毛玻璃拟态（Glassmorphism），移动端与桌面端自适应。
- **动态组件**：高精实时秒表时钟、落樱飘瓣（Sakura Canvas）、浪漫背景音乐控制器（解决现代浏览器 Autoplay 拦截）。
- **人文档案**：收录小白个人档案（生日 11月10日、座右铭）、余秋雨《你不懂我 我不怪你》典藏诗篇弹窗、周杰伦《最长的电影》等记忆微视频。
- **每日一言**：内置舔狗日记 68 条精选离线日记池，支持一键切换、一键复制到剪贴板。

## 🚀 本地调试与部署

- **纯静态模式（极速预览）**：
  直接使用任意本地静态服务器（全站所有核心功能、诗歌、日记、3D相册、落樱、时钟均已离线解耦）：
  ```bash
  python -m http.server 8080
  # 访问 http://127.0.0.1:8080
  ```
- **PHP 生产环境（支持音乐搜索与 API）**：
  ```bash
  php -S 127.0.0.1:8080
  ```
- **线上发布**：
  配置 Nginx / 宝塔根目录指向当前目录，支持 HTTPS 访问。已全面消除 Mixed Content 与外部脆弱死链依赖。
